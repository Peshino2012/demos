# Demos

Ejemplos de páginas web y de automatización de planillas. Son proyectos de
demostración: todos los nombres, datos y precios son ficticios.

- `abogados/`: landing page de un estudio de abogados (español e inglés).
- `curso-excel/`: página de venta de un curso online (español e inglés).
- `reporte-excel/`: reporte de ventas generado automáticamente con Python.

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
